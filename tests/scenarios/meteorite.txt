// Every island carries one deterministic moon meteorite: hand-mineable Moon Rock
// plus a crystal core, the raw material of the escape route.
// Island 900 keeps the test off the islands real runs will use.
ds island goto 900
#expect Current island 900 centered at 7372800, 0, 0
execute in dontstarve:islands run forceload add {X-112} {Z-112} {X+112} {Z+112}
